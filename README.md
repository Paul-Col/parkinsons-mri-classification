# Parkinson's Disease Neuroimaging Classification

TM470 Computing and IT Project

## Aim

Investigate the use of machine-learning and deep-learning
techniques to classify neuroimaging scans associated with
Parkinson's disease.

## Dataset

Parkinson's Disease DAT and MRI Scans

Source:
Kaggle - rishikjha/parkinsons-disease-dat-and-mri-scans

## Planned investigation

1. Explore the dataset
2. Preprocess MRI and DAT images
3. Develop a baseline CNN
4. Improve the CNN
5. Investigate transfer learning
6. Compare MRI and DAT classification
7. Evaluate models
8. Investigate Grad-CAM explainability
